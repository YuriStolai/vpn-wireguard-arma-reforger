# Project Guide

The project is still in the planning phase. There are no setup, deployment, or
runtime commands to execute yet.

When implementation is approved, this guide will be the canonical home for:

- prerequisites and supported operating systems;
- safe setup and configuration procedures;
- validation and troubleshooting commands;
- rollback procedures for temporary network and firewall changes; and
- operational guidance for replacing or maintaining WireGuard peers.

Until then, see [`../specs/specs.md`](../specs/specs.md) for product
requirements and [`../specs/plan.md`](../specs/plan.md) for the technical plan.
