# Implementation Backlog

Task status is canonical in the batch files. A task is `done` only when its
deliverable is implemented and its validation evidence is recorded without
sensitive data.

| Batch | Purpose | Status |
| --- | --- | --- |
| [`01-foundation/README.md`](01-foundation/README.md) | Validate constraints and select the design | `todo` |

## Workflow

Start a task only after reading the specification and plan. Record concise,
reproducible validation evidence in the task; put detailed sanitized command
history in [`../operations/`](../operations/README.md). Update
[`../next-session.md`](../next-session.md) when pending work changes the next
safe action.
